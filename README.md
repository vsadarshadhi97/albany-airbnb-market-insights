\# Albany Airbnb Market Insights



An interactive data analytics dashboard exploring Airbnb listings in Albany, New York. Built with Python, Streamlit, and Plotly, with a Gemini-powered AI assistant for asking questions about the dataset.



\## Project Features



\- Explore Airbnb listings and filter by room type.

\- View key metrics, including listing count and median nightly price.

\- Explore the distribution of nightly prices.

\- Compare median nightly prices across room types.

\- Ask the AI assistant questions about the selected listings and their price summaries.



\## Tools and Technologies



\- Python

\- Pandas

\- Plotly

\- Streamlit

\- Google Gemini API
